\begin{abstract}
待写要点：说明视频到动作扩散机器人策略中的固定噪声调度问题；指出不同状态对视频去噪预算的需求并不一致；概括本文提出的累计 Hazard 停止控制与相对 jump 噪声推进；总结路径级质量--代价优化与整体实验结论。
\end{abstract}

\keywords{机器人学习, 扩散策略, 自适应噪声调度, Hazard 停止控制, 跳步调度}

\section{引言}

\begin{itemize}
  \item 交代研究背景：视频到动作扩散式机器人策略在复杂操作任务上有效，但视频分支推理成本高，固定噪声步数会直接决定系统时延。
  \item 提出核心问题：统一的固定调度无法根据状态难度、任务复杂度和当前去噪进展自适应分配计算预算。
  \item 说明现有不足：只做固定步数推理会造成浪费；只做早停无法回答“若继续，应再推进多远”；纯离散 step 选择不够自然，难以表达剩余噪声空间中的相对推进。
  \item 给出本文思路：把视频分支的噪声调度建模为顺序决策问题，同时学习“现在是否停止”和“继续时应该跳多远”。
  \item 提前概括方法：本文提出 State-Adaptive Noise Trajectory Scheduler（SANTS），使用累计 Hazard 建模稳定的停止控制，使用相对 jump 比例建模继续动作，并以路径级动作质量与计算代价联合优化调度策略。
  \item 提前概括实验：围绕 RobotWin 全量任务验证自适应调度在成功率、平均视频步数和视频时延上的效果--效率权衡优势。
  \item 列出贡献：提出 SANTS 统一调度框架；提出累计 Hazard 停止与相对 jump 推进的联合建模；验证 SANTS 在机器人策略推理中的价值。
\end{itemize}

  \subsection{问题设定与方法概览}


我们将问题重新定义为\textbf{学习一条状态依赖的噪声推进轨迹}，而不是对所有样本采用同一条固定的流匹配积分日程。具体而言，SANTS 在每个视频决策点同时决定当前是否终止积分，以及若继续，下一次沿噪声轴推进多远。这一重定义来自我们对视频生成究竟如何作用于动作生成产生的思考，是否需要预测视频？预测的视频需要完全清晰的像素级的建模吗？（这里补跑FASTWAM，找他的漏洞），任务的不同难度阶段对视频指导需求是否不同？针对这些疑问，我们对不同视频去噪深度对动作的生成影响进行了系统比较：首先对数据集中的20000个episode进行人工标注，之后我们定义了25个固定的离散噪声强度均匀分布在流匹配积分的0到1之间，通过取定一个确定episode，让视频去噪积分到预设好的噪声强度离散点，再让同一个chunk不同噪声强度的预测视频指导动作的生成，为了比较对动作生成的影响，我们将动作反解回真实动作空间，再进行loss求解，最终将结果归一化到0和1之间，得到结果如图1所示。随着视频预测逐步变得更清晰，下游动作误差在大多数状态上确实会持续下降，但这种收益并非无限增长，往往会在中等去噪深度附近进入平台；更重要的是，简单的轨迹比如迫近物体，随着视频去噪加深带来的动作准确度增益较低，而任务困难阶段果上来看随着去噪程度加深，会有更高的收益。但是在困难阶段一部分状态上，继续逼近最清晰的视频预测反而会使动作误差回升。对这些失败样本的回看表明，问题通常并不来自“视觉不够清楚”，而是来自视频模型在后期去噪阶段产生了物理上不合理或动力学上不一致的预测，尤其是机械臂要接触到物体进行精细操作的阶段。因此更强的视觉锐化并不必然对应更可靠的动作条件。由此可见，固定视频噪声调度难以同时兼顾精度与效率：它既无法在简单状态上及时停下，也无法避免在部分困难状态上继续朝错误的视频动力学方向过度细化。前者主要服务于保持动作精度并减少无效计算，后者则主要服务于在继续的前提下压缩低价值更新，从而进一步提升推理效率。基于这一目标，本文将视频推理过程重写为一个由 SANTS 控制的顺序决策过程。


基于上述问题定义，本文方法的执行流程如下。设第 \(k\) 个视频决策点的当前噪声水平为 \(\sigma_k\)，对应的视频状态表征为 \(z_k\)。冻结的视频主干首先在 \(\sigma_k\) 下执行一次前向计算，并从当前视频隐表示中提取紧凑状态表征 \(z_k\)；调度器再基于 \(z_k\) 同时预测停止风险增量 \(\Delta H_k\)，以及继续积分时的相对噪声推进比例 \(r_k\)。若策略判定当前视频表征已经足以支持动作预测，则系统在该终止状态处停止视频积分、刷新缓存，并将终止后的视觉表征交给动作分支生成最终动作；若策略选择继续，则根据 \(r_k\) 将当前噪声水平从 \(\sigma_k\) 推进到下一状态 \(\sigma_{k+1}\)，并在新的噪声水平上继续视频推理。下面依次介绍状态与策略输出、停止机制与噪声推进策略。

\end{itemize}

\section{方法}

\subsection{冻结视频--动作策略接口}
\label{sec:method-policy-interface}

SANTS 构建在一个预训练的视频到动作扩散策略之上，而不是引入新的机器人策略主干。记冻结的视频--动作 Transformer 为 \(f_{\phi}\)。该策略在噪声水平 \(\sigma_k\) 下维护视频潜变量 \(x_k\)，每次视频去噪前向都会预测用于更新潜变量的流场。我们同时从该前向过程中提取视频 token 的池化隐藏表示 \(z_k\)，作为调度器的状态输入。当调度器在终止状态 \(x_{\tau}\) 和终止噪声水平 \(\sigma_{\mathrm{term}}\) 处停止后，动作分支基于该终止视频表征生成动作片段 \(\hat{a}_{\tau}\)。

这一接口将调度学习与策略学习解耦。SANTS 只观测 \((z_k,\sigma_k)\)，并决定当前是否停止以及继续时沿噪声轴推进多远；它不更新 Transformer blocks、视频输出头、动作输出头或动作去噪过程。因此，不同调度策略都在相同的策略容量下比较，学习到的调度模块也可以接入任何能够暴露中间视频特征并支持非均匀噪声水平更新的兼容视频--动作扩散策略。

基于上述接口，本文将固定视频去噪日程改写为一条由 SANTS 控制的状态依赖噪声轨迹。设第 \(k\) 个视频决策点的当前噪声水平为 \(\sigma_k\)，对应的视频状态表征为 \(z_k\)。冻结的视频主干首先在 \(\sigma_k\) 下执行一次前向计算；调度器再以 \((z_k,\sigma_k)\) 为状态，并由同一调度头输出两个量：用于停止建模的风险增量 \(\Delta H_k\)，以及用于继续推进的相对噪声比例分布。前者判断当前视频状态是否足以支持动作生成，后者决定若继续推理，应在剩余噪声空间中保留多少中间去噪过程。若策略判定停止，则系统结束视频积分并将终止表征交给动作分支；若策略选择继续，则根据采样到的推进比例将噪声水平推进到 \(\sigma_{k+1}\)，并在新的噪声水平上继续视频推理。下面依次介绍停止机制、噪声推进策略、路径级奖励和调度器训练。

\subsection{停止风险与相对噪声推进}

\paragraph{基于累计停止风险的终止机制}
为将早停写成与实际采样路径一致的序列决策过程，我们用 \(k\) 表示当前调度决策索引，并令随机变量 \(T\) 表示视频积分首次终止的决策步。路径能够到达第 \(k\) 步等价于 \(T\ge k\)；在这一条件下，\(T=k\) 表示当前步停止，\(T>k\) 表示当前步继续。基于这一记号，停止头先根据当前状态 \((z_k,\sigma_k)\) 产生一个标量停止分数，并通过
\begin{equation}
\Delta H_k = \mathrm{softplus}(g(z_k,\sigma_k)),
\label{eq:sants-hazard-inc}
\end{equation}
将其映射为非负的新增停止量。由于式~(\ref{eq:sants-hazard-inc}) 保证 \(\Delta H_k\ge 0\)，这些增量可以沿路径累加为
\begin{equation}
H_k = \sum_{i=1}^{k}\Delta H_i,
\label{eq:sants-hazard-cum}
\end{equation}
其中 \(H_k\) 汇总了截至第 \(k\) 步已经积累的终止趋势。基于 \(H_k\)，我们进一步定义截至第 \(k\) 步已经停止的累计停止概率
\begin{equation}
F_k = P(T\le k) = 1-e^{-H_k}.
\label{eq:sants-stop-cdf}
\end{equation}
它回答的是一个全局问题：到当前为止，路径是否已经积累了足够的停止证据。相应地，由
\begin{equation}
1-F_k = (1-F_{k-1})e^{-\Delta H_k},
\label{eq:sants-stop-rec}
\end{equation}
可得当前步的条件停止概率
\begin{equation}
h_k = P(T=k \mid T\ge k) = 1-\frac{1-F_k}{1-F_{k-1}} = 1-e^{-\Delta H_k},
\label{eq:sants-stop-prob}
\end{equation}
其中 \(h_k\) 回答的是局部动作问题：既然路径已经走到第 \(k\) 步，现在应当停止的概率是多少。

条件停止概率用于区分训练期的局部决策分布与部署期的全局终止证据。由于路径到达第 \(k\) 步已经隐含前 \(k-1\) 步均未停止，停止头在训练时应建模 \(P(T=k\mid T\ge k)\)，而不是整条路径最终停在第 \(k\) 步的边缘概率。因此，我们使用 \(h_k\) 进行 \(\mathrm{Bernoulli}\) 采样，使采样分布与当前步决策一致；部署时则使用累计停止概率 \(F_k\) 与阈值 \(\eta\) 判断截至当前是否已有足够终止证据。累计停止风险参数化将 \(h_k\) 与 \(F_k\) 统一在同一路径概率分解中。

\paragraph{相对噪声推进策略}
停止机制只决定何时结束积分，仍需决定继续时沿噪声轴推进多远。若继续动作只能沿固定日程前进一步，所有状态都会共享同一离散积分网格，难以在动作意图明确的状态上跳过低价值更新，也难以在接触关系复杂或未来演化不确定的状态上保留细粒度推理。基于这一考虑，SANTS 将继续动作建模为相对噪声推进比例，使简单状态可以采用更大推进幅度以节省预算，复杂状态可以采用更小推进幅度以保留中间去噪过程：
\begin{equation}
r_k \sim \mathrm{Beta}(\alpha_k,\beta_k), \qquad \sigma_{k+1}=r_k\sigma_k,
\label{eq:sants-jump-ratio}
\end{equation}
其中 \(r_k\in(0,1)\) 表示保留到下一步的相对噪声比例，而 \(1-r_k\) 表示沿噪声轴推进的相对推进距离。因此，\(r_k\) 接近 \(1\) 对应更保守的小步推进，\(r_k\) 较小时则对应更激进的大步推进。式~(\ref{eq:sants-jump-ratio}) 使调度器直接在连续噪声空间中选择下一积分时间步，而不是受限于固定离散步长。

为使训练期的随机探索与部署期的确定性推进共享同一参数化，我们不直接自由预测 \(\alpha_k\) 和 \(\beta_k\)，而是先预测推进比例的众数 \(m_k\in(0,1)\) 与分布集中度 \(c_k>2\)，再构造
\begin{equation}
\alpha_k = m_k(c_k-2)+1,\qquad \beta_k=(1-m_k)(c_k-2)+1.
\label{eq:sants-jump-param}
\end{equation}
这一设计保证 \(\alpha_k>1\) 且 \(\beta_k>1\)，从而 Beta 分布具有稳定的内部众数；相应地，部署时使用
\begin{equation}
r_k^{\mathrm{mode}}=\frac{\alpha_k-1}{\alpha_k+\beta_k-2}=m_k
\label{eq:sants-jump-mode}
\end{equation}
作为确定性推进比例，而训练期则从式~(\ref{eq:sants-jump-ratio}) 对应的分布中直接采样 \(r_k\)，以保留路径探索。状态更新时，视频潜变量通过支持任意 \((\sigma_k,\sigma_{k+1})\) 的连续积分更新算子从 \(\sigma_k\) 推进到 \(\sigma_{k+1}\)。需要强调的是，每次调度决策之前都必须先执行一次视频前向以获得当前状态；若第 \(k\) 步选择停止，该步计入一次调度决策，但不会再产生新的视频状态更新；只有在选择继续并实际执行上述状态更新时，实际视频状态更新次数才会增加。因此，本文在效率统计中显式区分调度决策次数与实际视频状态更新次数。

\subsection{终止动作生成与路径级奖励函数}

\paragraph{终止状态的动作生成}
SANTS 在完整调度路径结束后计算奖励，而不是评价单个停止或推进决策。给定路径 \(\tau\)，视频分支终止于噪声水平 \(\sigma_{\mathrm{term}}\)，并得到终止视频状态 \(v_{\tau}\)。为了使动作分支接收的条件信息与调度器选定的终止状态一致，我们在 \(\sigma_{\mathrm{term}}\) 处重新计算视频条件表征，再由固定的动作去噪过程生成动作序列 \(\hat{a}_{\tau}\)。因此，路径价值不由内部停止分数决定，而由终止状态诱导的动作质量与视频推理预算共同决定。

\paragraph{动作语义误差}
我们不以视频清晰度作为奖励，而是在真实动作空间比较 \(\hat{a}_{\tau}\) 与示范动作 \(a^{\star}\)。奖励包含两类互补损失：序列动作损失 \(L_{\mathrm{seq}}\) 衡量每个未来动作在双臂位置、姿态与 gripper 状态上的误差，动作变化损失 \(L_{\Delta}\) 衡量相邻动作之间的变化趋势是否匹配示范轨迹。前者约束终止状态能产生正确动作目标，后者约束整段动作的动态连续性。实现中对大幅运动和 gripper 事件附近时间步加权，并跳过已观测的条件动作帧；完整损失定义放在补充材料中。

\paragraph{双锚点质量归一化}
直接使用绝对动作误差作为奖励会混合样本难度与调度质量，因此我们使用两个固定预算参考路径来归一化当前路径的收益。具体地，对同一状态额外运行一个低预算参考路径 \(\tau_{\mathrm{lo}}\) 和一个高预算参考路径 \(\tau_{\mathrm{hi}}\)，分别得到动作 \(\hat{a}_{\mathrm{lo}}\) 和 \(\hat{a}_{\mathrm{hi}}\)。第~3.1 节的固定去噪深度实验显示，在样本平均意义上，更充分的视频去噪通常带来更低的动作误差，因此低预算参考路径可视为过早停止参照，高预算参考路径可视为充分推理参照。对任一误差类型 \(m\in\{\mathrm{seq},\Delta\}\)，令 \(G_m\) 表示低预算到高预算之间的可恢复误差空间，并在数值上使用很小的下界避免分母退化；其具体定义放在补充材料中。当前路径相对于低预算参考路径的归一化收益写为
\begin{equation}
u_m(\tau)=
\mathrm{clip}_{[-1,1]}\!
\left(
\frac{
L_m(\hat{a}_{\mathrm{lo}},a^{\star}) -
L_m(\hat{a}_{\tau},a^{\star})
}{G_m}
\right).
\label{eq:sants-anchor-gain}
\end{equation}
这里 \(u_m(\tau)\) 表示当前路径相对于低预算参考路径恢复了多少动作质量。当低预算与高预算本身差异很小时，继续视频推理并没有明显可恢复空间；为避免这类样本主导训练，我们引入难度系数
\begin{equation}
D_m =
\frac{
\max\!\left(L_m(\hat{a}_{\mathrm{lo}},a^{\star}) -
L_m(\hat{a}_{\mathrm{hi}},a^{\star}), 0\right)}
{
\max\!\left(L_m(\hat{a}_{\mathrm{lo}},a^{\star}) -
L_m(\hat{a}_{\mathrm{hi}},a^{\star}), 0\right) + \kappa},
\label{eq:sants-difficulty}
\end{equation}
其中分子表示高预算参考路径相对于低预算参考路径带来的误差下降。最终的质量项奖励正向恢复收益，同时惩罚比低预算参考路径更差的调度结果：
\begin{equation}
Q_m(\tau)=
w_m\left(
D_m\max(u_m(\tau),0)
-\lambda_{\mathrm{pen}}\max(-u_m(\tau),0)
\right),
\qquad
Q(\tau)=Q_{\mathrm{seq}}(\tau)+Q_{\Delta}(\tau).
\label{eq:sants-quality}
\end{equation}
这种双锚点设计使奖励关注“当前路径是否以有限预算恢复了高预算路径中的有效动作语义”，而不是简单偏好所有样本都使用最多视频去噪步骤。更重要的是，式~(\ref{eq:sants-quality}) 不假设每个状态都服从平均曲线：当高预算相对低预算没有带来明显改善时，\(D_m\) 会压低正向收益，而负向项仍会惩罚比低预算更差的路径，因此调度器可以在平台化或反向收益的状态上学习提前终止。

\paragraph{质量--成本路径回报}
最终回报在动作语义质量和视频推理代价之间做显式权衡。设 \(n_{\tau}\) 为路径 \(\tau\) 实际执行的视频状态更新次数，\(K_{\max}\) 为最大视频预算。我们使用归一化的单调成本
\begin{equation}
C(n_{\tau}) =
\lambda_c
\frac{\sum_{i=1}^{n_{\tau}} c_i}{\sum_{i=1}^{K_{\max}} c_i},
\qquad
c_i=c_0+c_1\left(\frac{i}{K_{\max}}\right)^{\gamma},
\label{eq:sants-cost}
\end{equation}
并将路径回报定义为
\begin{equation}
R(\tau)=Q(\tau)-C(n_{\tau}).
\label{eq:sants-reward}
\end{equation}
该回报只在动作序列生成完成后计算，因此它直接对应路径级策略优化目标：调度器只有在额外视频更新带来足够动作语义收益时才会获得更高回报。换言之，SANTS 并不学习一个人工标注的最优停止步，而是通过式~(\ref{eq:sants-reward}) 在数据驱动的动作质量和推理成本之间学习状态依赖的预算分配。

\subsection{轻量级调度器后训练}
\label{sec:method-training}

我们只训练调度器参数，并保持视频--动作策略冻结。对每个示范片段，当前调度器采样一条完整的停止--推进轨迹 \(\tau\)。在第 \(k\) 步，冻结策略产生视频状态表示 \(z_k\)，调度器从 \(h_k\) 中采样停止决策；若继续，则采样相对推进比例 \(r_k\)，并令 \(\sigma_{k+1}=r_k\sigma_k\)。轨迹终止后，冻结动作分支生成动作片段 \(\hat{a}_{\tau}\)。同一输入还会用低预算和高预算固定日程各执行一次，作为上一节路径奖励中的两个参考锚点。因此，调度器由最终动作质量和实际执行的视频状态更新次数共同监督，而不需要人工标注最优停止步或最优跳步长度。
我们使用路径级 PPO 更新调度器，并加入轻量 reference regularization，使训练早期的停止和推进分布保持在固定日程附近。主实验中，该后训练阶段只更新一个小型 MLP 调度头，所有主干和动作生成参数均保持冻结。若存在目标域数据，同一目标也可以继续微调调度器，而不需要重新训练机器人策略。

\section{实验}

\subsection{实验问题与设置}
\label{sec:exp-setup}

本节实验回答三个问题：\textbf{Q1} 视频生成作为中间表征究竟如何帮助动作生成；\textbf{Q2} SANTS 能否通过状态依赖的精准去噪控制，在保持任务成功率的同时显著提升 WAM 推理速度并形成更好的效果--效率权衡；\textbf{Q3} SANTS 的性能增益来自哪些设计选择，我们通过消融实验验证停止决策、相对噪声推进、路径级训练和目标域微调的作用。

实验中的视频--动作策略采用 Wan2.2-5B 作为视频骨干，并将未来视频 latent 与动作 token 输入同一个 Transformer 主干进行联合建模。视频与动作分别使用模态专属的输入头和输出头，中间 Transformer blocks 在两类 token 之间共享参数；在推理流程中，动作去噪阶段读取视频去噪终止后的中间表征作为条件，因此动作生成会直接受到视频去噪深度和终止状态的影响。SANTS 附着在该共享骨干的视频去噪过程上，根据当前视频状态表示和噪声水平决定是否停止以及如何推进噪声轨迹。调度器训练阶段冻结视频骨干、视频头和动作头，只更新轻量调度器参数，从而将性能变化归因于推理时的噪声调度策略。

我们使用多样化示范片段对调度器进行轻量后训练，而不是重新训练视频--动作策略。训练数据从仿真与实机视频--动作轨迹中采样，包含 LIBERO、RoboCasa、Meta-World 等仿真操作数据，外加部分公开和自采实机轨迹。由于调度器只接收冻结策略的中间表征和噪声水平，其训练目标不是存储任务知识，而是学习不同状态下的视频去噪预算分配。我们评测两种部署方式：直接使用该通用调度器，以及在目标工作域数据上仅微调调度器 \(3000\) step。两种方式均保持视频--动作策略冻结。

我们选择 LingBot-VA、Motus、Fast-WAM 和 \(\pi_{0.5}\) 作为基线模型。LingBot-VA 是一种视频--动作联合建模策略，通过视频预测表征和动作生成共同建模机器人控制。Motus 是统一 latent action world model，在潜在动作空间中连接世界建模与策略执行。Fast-WAM 关注 WAM 在测试时是否需要完整未来想象，并给出面向快速推理的策略设计。\(\pi_{0.5}\) 是面向开放环境泛化的 VLA 策略，强调跨场景、跨任务和跨 embodiment 的机器人控制能力。仿真评测包括 RobotWin 全量任务和 LIBERO-plus；真实机器人评测包含待定的真实任务集合，每个任务进行 \([N]\) 次独立试验。主要指标为任务成功率，效率指标包括平均视频去噪步数、视频去噪时延和端到端策略时延。

\subsection{主结果：全量 RobotWin 在线评测}

\begin{itemize}
  \item 主表重点展示：自适应调度在全量任务上的整体成功率。
  \item 同时给出平均视频步数和平均视频时延，避免只讲速度不讲效果，或者只讲效果不讲效率。
  \item 强调论文主结果应写成效果--效率联合结论，而不是拆成两张互相割裂的表。
\end{itemize}

\subsection{与固定步数 Baseline 的对比}

\begin{itemize}
  \item 系统比较不同固定步数下的成功率、步数与时延。
  \item 说明固定高预算为什么浪费，固定低预算为什么会在困难状态下掉性能。
  \item 突出自适应调度不是简单取某个中间固定步数，而是对不同状态做不同预算分配。
\end{itemize}

\subsection{效果--效率权衡分析}

\begin{itemize}
  \item 展示 success rate 与 runtime 或 video steps 的 tradeoff 曲线。
  \item 解释不同任务或不同状态为何会触发不同的平均预算分配。
  \item 用任务级统计说明：简单任务倾向更早停止，复杂任务倾向保留更多去噪预算。
\end{itemize}

\subsection{消融实验}

\begin{itemize}
  \item 比较 stop-only 与 stop+jump，验证统一调度的必要性。
  \item 比较不同停止建模方式，验证累计 Hazard 的稳定性和收益。
  \item 比较不同 jump 参数化或不同 reference regularization，分析哪部分设计真正带来提升。
  \item 比较不同奖励项组合，验证质量项、趋势项和成本项分别发挥的作用。
\end{itemize}

\subsection{调度行为分析}

\begin{itemize}
  \item 展示终止噪声水平、平均相对推进距离、平均调度决策次数等调度统计量。
  \item 可视化典型轨迹，说明调度策略如何在不同任务阶段分配计算预算。
  \item 分析策略是否学会了“难例多算、易例少算”的状态依赖行为。
\end{itemize}

\subsection{失败案例与误差分析}

\begin{itemize}
  \item 识别仍然表现不稳定的任务，分析问题更偏向感知困难、动作困难还是调度失误。
  \item 区分典型失败模式：停得过早、跳得过远、预算分配不稳定、最终表征不足以支撑动作预测。
  \item 说明这些失败模式如何为后续改进提供方向。
\end{itemize}

\section{局限性}

\begin{itemize}
  \item 当前实验主要集中在 RobotWin，跨数据域、跨模型主干和跨机器人平台的泛化能力还需要补充验证。
  \item 当前训练设置冻结主干，因此本文主要回答“调度是否有效”，尚未回答“调度与表征联合优化是否更强”。
  \item 当前部署仍依赖少量阈值型超参数，后续可以探索更少手工规则的决策接口。
  \item 当前主要优化视频分支预算，尚未统一考虑整条系统链路中的所有开销来源。
\end{itemize}

\section{结论}

\begin{itemize}
  \item 回到问题本身：固定噪声调度不适合状态难度差异明显的机器人推理场景。
  \item 总结核心方法：通过累计 Hazard 停止控制与相对 jump 噪声推进，学习状态依赖的自适应调度策略。
  \item 总结核心发现：扩散式机器人策略的推理预算应该由状态决定，而不是由固定 schedule 决定。
  \item 指出未来方向：可继续扩展到联合主干训练、更广泛基准和更完整的系统级预算优化。
\end{itemize}
